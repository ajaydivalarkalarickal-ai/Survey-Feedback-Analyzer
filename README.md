# Survey Feedback Analyzer

A beginner-friendly Python project that analyzes textual survey feedback using core programming concepts such as dictionaries, loops, conditionals, string operations, and user-defined functions.

## Project Objective

The goal is to clean survey comments, add new feedback entries, analyze commonly used words, calculate rating statistics, and generate simple insights from textual feedback.

## Tools & Concepts

- Python
- Dictionaries and Lists
- Loops and Conditionals
- String Cleaning
- User-Defined Functions
- Basic Text Analysis
- Google Colab / Jupyter Notebook

## Project Workflow

1. Start with preloaded survey feedback and ratings.
2. Accept additional feedback from the user.
3. Clean text by removing punctuation, extra spaces, and inconsistent capitalization.
4. Create a reusable function to count selected words in feedback.
5. Calculate the average rating.
6. Identify the longest feedback comment.
7. Extract unique words used across the feedback.
8. Practice sorting feedback by rating.

## Repository Contents

## Skills Demonstrated

`Python Fundamentals` • `Data Cleaning` • `String Processing` • `Functions` • `Loops` • `Dictionaries` • `Basic Text Analysis`

## Learning Outcome

This project demonstrates how fundamental Python concepts can be combined to transform unstructured feedback into simple, useful insights. It also provides a foundation for more advanced text analytics and sentiment-analysis projects.
